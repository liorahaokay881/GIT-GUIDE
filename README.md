## 🧠 Understanding Danger Levels

One of the best features of GIT-GUIDE is the danger level system. This protects beginners from accidentally deleting their work. Every command is color-coded:

-   🟢 **Safe (Green):** These commands are harmless. You can run them anytime. Examples include checking your status or viewing a list of files.
-   🟡 **Caution (Yellow):** These commands change something but can usually be undone. Examples include moving files or creating new branches.
-   🔴 **Dangerous (Red):** These commands can permanently remove or rewrite data. Examples include forcing a delete or resetting your hard drive. GIT-GUIDE will always warn you clearly before you proceed with these.

Always take a second to look at the color indicator before typing a command. This simple habit will save you from many headaches.
